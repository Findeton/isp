## 3. Two admitted hybrid regimes

The successor must distinguish two regimes rather than pretend one theorem
covers all operator-algebraic settings.

### 3.1 Finite retained records

For a boundary with finite retained-record set $R_D$ and unital quantum
observable algebra $\mathcal A_D$, define the hybrid observable algebra

$$
\mathcal O_D
=\ell^\infty(R_D)\otimes\mathcal A_D
\cong\bigoplus_{r\in R_D}\mathcal A_D.
$$

No measure is needed. This regime is mandatory and supplies the exact positive
control for mid-circuit measurements and finite adaptive laboratory programs.

The quantum algebra $\mathcal A_D$ must include every quantum system, open
probe, and quantum memory port needed by later registered operations. The
record set $R_D$ must contain every retained classical value. Procedure names,
slot labels, and run tokens are not record coordinates.

a supplied faithful normal technical reference state or equivalent faithful

Define

$$
\mathcal O_D
=\mathcal A_D\,\overline\otimes\,
L^\infty(R_D,\nu_D).

Only the measure class is structural. Replacing $\nu_D$ by an equivalent
measure produces the canonically isomorphic hybrid algebra and cannot change
any prediction. The reference state/weight is a technical domination device,
not the cosmological state, actual state, preferred ensemble, or

### 4.3 Complete instruments, branches, and nonselection

A complete finite instrument with outcomes $s\in S$ is one arrow, not a list
of unrelated branches:

$$
\widehat{\mathcal J}:
\bigoplus_{s\in S}\mathcal A_E
\longrightarrow\mathcal A_D,
\qquad
\widehat{\mathcal J}((A_s)_s)
=\sum_{s\in S}\mathcal J_s(A_s).

The branch map is recovered by inserting into one central summand. The
nonselective operation is recovered by restricting to the diagonal constant
family $A_s=A$. Neither branch nor nonselective restriction is the complete
hybrid arrow.

For a standard-Borel instrument, the analogous complete arrow is the supplied
normal extension over $L^\infty(S,\mu)$. Events are central projections
