## Rules

1. Every load-bearing input enters before construction consumes it.
2. `STANDARD-THEORY` means a comparator fixed by prior empirical success; it
   is not an ISP derivation.
3. `CONTROL` means an intentionally declared test family; passing it proves
   only compatibility within that family.
4. `HYPOTHESIS` means a proposed physical principle with a registered
   discriminator.
5. `DERIVED` is allowed only after a theorem or adjudicated measurement names
   its exact upstream inputs.
6. A renamed input remains an input.
7. Calibration and held-out testing use disjoint rows or explicitly model the
   covariance.
8. No count is a probability without a measure. No order is time without
   clocks/influence. No curvature is gravity without dynamics.

## Accretion alarms

A unit stops for scope review if any of the following occurs:

- a new variable is introduced only after a target gate fails;
- a target parameter is inserted into the candidate law under a new name;
- a hidden state has no registered readout yet is called physical;
- a finite fitting table grows with the number of experiments;
- a dimension, topology, causal order, or metric is chosen to make an
  estimator pass;
- an apparatus variable appears in the universal law rather than the typed
  experiment;
- a cosmological boundary condition is called a law because it is unknown;
- a representation redundancy is counted as new ontology;
- a source, clock, or calibration is reused as held-out evidence.
