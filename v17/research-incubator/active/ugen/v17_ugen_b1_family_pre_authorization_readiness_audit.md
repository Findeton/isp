## 0. Executive verdict

The post-A1 matter-law triage selected Bell-type QFT as the highest-value
possible next **prior-art family** because it combines ordinary-positive
configuration actuality with particle creation and annihilation. A deeper
source audit now reveals that, within the exact corpus audited here, this
family-level description joins results that do not coexist in one
source-fixed model.

1. The exact all-time nonexplosion theorem is for a **countable lattice**
   configuration process under explicit Hamiltonian/state assumptions.
2. Broad continuum Bell-type QFTs with creation and annihilation are defined
   for regularized quantum Hamiltonians, but the construction paper explicitly
   leaves general process existence, cutoff removal, and Lorentz invariance
   open.
3. Continuum nonrelativistic interior-boundary-condition (IBC) Hamiltonians can
   be self-adjoint and ultraviolet finite, but the associated actual
   configuration processes and their equivariance are developed explicitly at
   a non-rigorous level; the relevant process limits are evidence or
   conjecture, not global process theorems.
4. A relativistic multi-time IBC model has rigorous global wavefunction
   evolution and probability conservation in $1+1$ dimensions with finitely
   many Fock sectors, but it does not construct the corresponding actual
   stochastic configuration history and is only almost fully Lorentz
   covariant at its printed scope.

Therefore no single model among the exact audited sources satisfies the
minimum core needed for the advertised B1 control:

$$
\boxed{
\begin{gathered}
\text{one named fixed dynamics}
+\text{an actual sector-changing path law}\\
+\text{all-time existence for that same path law}.
\end{gathered}}
\tag{1}
$$

A reality-grade matter law would additionally need continuum control,
relativistic covariance, physical readers, empirical transfer, and native
source depth. Those are benchmark coordinates, not post-hoc requirements for
every bounded prior-art control. B1 fails earlier: the lattice result is a
conditional class theorem rather than one source-fixed sector-changing
physical member, while the named continuum members lack a global actual-path
theorem.

The correct readiness verdict is

$$
\boxed{
\text{B1-FAMILY-HIGH-INFORMATION}
\quad/\quad
\text{B1-SINGLE-MODEL-NOT-FREEZE-READY}.}
\tag{2}
$$

This is not a rejection of Bell-type QFT. It prevents v17 from assembling one
apparently mature control by silently borrowing the lattice existence theorem,
the continuum IBC Hamiltonian, and the relativistic multi-time theorem from
different physical objects.

## 2. Freeze-readiness vector

A future B1 model would need one immutable tuple

$$
\mathfrak B=(A,G,V,C,L,H,R,E,N),
\tag{3}
$$

where:

| coordinate | freeze question |
|---|---|
| $A$ actual history | Is one-run reality an explicitly typed path or process? |
| $G$ global process | Does one normalized nonexplosive process exist for the full declared time domain? |
| $V$ variable number | Are creation and annihilation represented by the same law? |
| $C$ continuum | Is the configuration carrier continuum rather than a lattice regulator? |
| $L$ relativity | Is the process covariant without an uncharged preferred slicing? |
| $H$ dynamics | Is the Hamiltonian/evolution mathematically defined at the same scope as the process? |
| $R$ readers | Are interventions, apparatus records, divisions, and erasers generated or transferred? |
| $E$ empirical transfer | Does one fixed law make no-refit predictions beyond supplied standard-QFT records? |
| $N$ native depth | Is the target quantum state/current/process absent from the explanatory inputs? |

`Yes` below means proved for the same model. `Formal` means a formula or
architecture exists without the required global theorem. `Conditional` means
the coordinate is inherited from supplied quantum physics. `No` means absent
or outside the declared model.

A bounded B1 prior-art control need not answer `Yes` on every coordinate. It
must, however, bind all nine statuses to **one model**, and its minimum
freeze-eligibility core is

$$
A=G=V=H=\text{yes for the same named sector-changing model}.
\tag{3a}
$$

The coordinates $C,L,R,E,N$ then determine physical reach and may remain
explicit debts. Equation (3a) prevents two opposite errors: choosing a toy
solely because it is easy to prove, and rejecting a useful bounded control
merely because it is not already a complete relativistic theory of matter.

## 4. Four distinct source objects

### 4.1 B1-GEN — broad regularized Bell-type QFT

The general construction starts from:

1. a Hilbert space;
2. a unitary one-parameter group with Hamiltonian $H$;
3. a chosen configuration POVM/PVM $P$;
4. a supplied state vector $\Psi_t$;
5. the quantum-current minimal jump rates.

For a transition from $q'$ to $q$, the schematic rate is

$$
\sigma_t(dq\mid q')
=
\frac{
\left[
(2/\hbar)\operatorname{Im}
\langle\Psi_t|P(dq)HP(dq')|\Psi_t\rangle
\right]^+
}{
\langle\Psi_t|P(dq')|\Psi_t\rangle
}.
\tag{4}
$$

This provides real physical insight: a standard quantum current can drive an
ordinary-positive actual configuration process with creation and annihilation.
It also exposes every decisive input. The source assumes a well-defined
Hamiltonian, often with cutoffs, and assumes a choice among possible position
observables.

The authors explicitly leave three broad gaps: the Klein--Gordon-associated
process, cutoff removal, and Lorentz invariance. They also state that rigorous
global existence is nontrivial and cite the lattice theorem as an example, not
as a continuum class theorem.

Verdict:

$$
(A,V,C) = \text{formal/conditional yes},
\qquad
H=\text{supplied/conditional},
\qquad
(G,L,R,E,N)=\text{open, partial, or no}.
\tag{5}
$$

### 4.2 B1-LAT — rigorous lattice jump process

The lattice theorem uses a countable state space. In Bell's physical example,
a state is an occupation function

$$
x:\Lambda\longrightarrow\mathbb Z_{+},
\qquad
\sum_{r\in\Lambda}x(r)<\infty,
\tag{6}
$$

on a countable lattice $\Lambda\subset\mathbb R^3$. It assumes a self-adjoint
Hamiltonian, an initial state, and a POVM/PVM satisfying domain and local
integrability conditions. Under Assumption A, it proves a unique-in-law
right-continuous Markov pure-jump process on all $t\in\mathbb R$, with the
prescribed equivariant marginals and almost-sure nonexplosion.

This is a genuine process-completion theorem. It is also exactly scoped:

1. the carrier is countable;
2. the law is Markov and externally time-parametrized;
3. the Hamiltonian, quantum state, and configuration observable are supplied;
4. the theorem does not provide continuum or Lorentz recovery;
5. its broadest easy sufficient conditions include finite $E$ with bounded
   $H$, or Hilbert--Schmidt $H$; the general good-state set is not characterized
   as physically large.

The source itself states that global existence for combined continuum models
with jumps remained open at its publication scope.

Number-changing jumps occur when the supplied Hamiltonian has matrix elements
between different occupation sectors; variable number is available in the
carrier, not forced by the existence theorem alone.

The paper proves its theorem for every tuple $(H,P,\Psi_0)$ satisfying
Assumption A. It does not itself freeze one named sector-changing physical
Hamiltonian and verify that tuple as the B1 member. Doing so would be a new
model-selection step rather than merely citing the existence theorem.

Verdict:

$$
(A,G,H)=\text{yes for the conditional theorem class},
\qquad
V=\text{conditional on sector-changing }H,
\qquad
C=L=R=E=N=\text{no or unearned}.
\tag{7}
$$

The conditional theorem is freezeable mathematics, but it is not yet the
intended reality-first B1 physics control. Selecting a toy member merely
because it has the strongest theorem would test a lattice construction rather
than the continuum/relativistic variable-number actuality gap for which B1 was
selected.

### 4.3 B1-IBC-NR — continuum ultraviolet-finite IBC process

The IBC programme gives mathematically defined nonrelativistic Hamiltonians on
continuum variable-number configuration spaces. The interaction is encoded by
a boundary relation between adjacent Fock sectors. For named models, the IBC
Hamiltonian is self-adjoint and generates unitary quantum evolution without a
UV cutoff.

The associated Bell-type process is physically attractive:

1. absorption is deterministic when a particle reaches the relevant collision
   boundary;
2. emission is stochastic with a rate fixed by current balance, Markovity, and
   time reversal;
3. the actual configuration has variable particle number;
4. space is continuum rather than lattice-regulated.

But the trajectory paper explicitly says that equivariance and the processes
are shown at a **non-rigorous level**. Its cutoff-removal discussion calls the
process convergence strong evidence, plausible conjecture, or a question for
future work. Self-adjointness of $H_{\rm IBC}$ proves global quantum evolution;
it does not separately prove that Bohmian flow plus boundary jumps defines one
nonexplosive actual process almost surely for all time.

The models are also nonrelativistic. Some use fixed infinitely massive sources;
the moving-source model remains a simplified scalar QFT rather than a
transferred Standard Model member.

Verdict:

$$
(V,C,H)=\text{yes at named nonrelativistic model scope},
\qquad
A=\text{formal},
\quad
G=L=R=E=N=\text{unearned}.
\tag{8}
$$

### 4.4 B1-IBC-REL — relativistic multi-time IBC prediction

The relativistic IBC source proves existence and uniqueness of a multi-time
wavefunction and local probability conservation on arbitrary Cauchy surfaces
for a model with

1. Dirac particles in $1+1$ dimensions;
2. sectors $1\le n\le N$ for a finite maximum $N$;
3. interaction at coincidence configurations;
4. both massless and massive cases at the printed scope.

This is a rigorous predictive-process result. It is not a theorem about one
actual stochastic configuration history. No Bell/IBC sample-path construction,
global nonexplosion theorem, apparatus reader, or stable-record descent is
provided in that paper.

The model is described as almost fully covariant because fixed matrices in its
interaction would need an additional transformation law for full Lorentz
invariance. The source identifies extension to higher dimensions and the
relativistic ultraviolet problem as open, including an obstacle to point
interactions for the Dirac operator in $1+3$ dimensions.

Verdict:

$$
(H,C)=\text{yes for the finite-sector }1+1\text{ predictor},
\qquad
V=\text{finite-sector predictive only},
\qquad
L=\text{partial},
\quad
A=G=R=E=N=\text{no or open}.
\tag{9}
$$

## 6. Why wavefunction existence is not history existence

This distinction is the central lesson shared with A1.

Suppose a self-adjoint $H$ gives

$$
\Psi_t=e^{-iHt/\hbar}\Psi_0
\tag{10}
$$

for all $t$. This proves a global predictive state. A Bell-type actual process
also requires:

1. existence of Bohmian integral curves away from nodes and boundaries;
2. a well-defined jump intensity on the evolving support;
3. almost-sure avoidance or controlled passage of singular sets;
4. nonaccumulation of infinitely many jumps in finite time;
5. a consistent path measure across all finite intervals;
6. equivariant marginals for that path measure.

The lattice theorem proves these duties under its Assumption A. The IBC
Hamiltonian theorem does not automatically transfer that proof to continuum
boundaries. Therefore

$$
\boxed{
\text{global unitary prediction}
\not\Rightarrow
\text{global actual-history process}.}
\tag{11}
$$

Equation (11) is not philosophical decoration. It is the exact point at which
combining the IBC papers would overclaim.

## 9. Reader and empirical ceiling

The general Bell source states that equivariance suffices for empirical
agreement provided all experimental outcomes are registered in the chosen
configuration variables. This is a clear conditional bridge, not a material
detector construction.

The same source gives an explicit ambiguity: two distinct equivariant
processes can arise from different uses of a position POVM/PVM extension and
may be empirically undecidable. Consequently:

1. equilibrium record agreement does not select the microscopic path law;
2. the standard QFT apparatus supplies the predictions;
3. no B1 source in this audit generates a complete detector, memory, eraser,
   and retained-division parent from its particle process;
4. no no-refit experiment distinguishes the minimal Bell path from another
   operationally equivalent equivariant completion.

Thus B1 has high ontological and mathematical diagnostic value but low direct
empirical selection value at present.

## 13. Routing verdict

B1 remains the highest-information **family**, but a B1 pin should not be
requested yet. This is not because a bounded control must already be continuum,
Lorentz complete, reader complete, or native. It is because none of the audited
sources supplies the smaller same-model core (3a). The available choices fail
that core or lose the intended physical question in a different way:

1. the lattice class is rigorous under Assumption A, but selecting and verifying
   one sector-changing member would be a new construction and would move away
   from the form-neutral reality question;
2. the continuum IBC model is physically closer but lacks rigorous process
   completion;
3. the relativistic IBC model is a predictive wavefunction theorem without the
   actual process B1 is supposed to test;
4. the generic regularized family is too broad for a result-neutral frozen
   model claim.

The next legitimate move is not to choose the least bad row. It is to retain
equation (1) as the minimum same-model process benchmark and vector (3) as the
full matter-law benchmark, then search existing physics for a single object
that closes more of them. If none exists, the programme should record that the
audited prior art does not yet supply a freeze-worthy actuality-bearing QFT
control.
