## 3. Refined cylinder descent

Let `Omega` be a finite set of refined durable histories and let `mu` be a
positive measure on it.  A partial history `H` denotes a positive cylinder
`[H]`.  Two record extensions `a` and `b` commute at the refined record level
when both orders denote the same cylinder:

```text
[Hab] = [Hba].
```

This is a statement about record identity, not merely equality of a coarse
terminal state.

### Theorem 1 — refined cylinder cocycle

If `mu([H])>0` and both routes denote the same refined cylinder, then

```text
mu([Ha])/mu([H]) * mu([Hab])/mu([Ha])
  = mu([Hab])/mu([H])
  = mu([Hb])/mu([H]) * mu([Hba])/mu([Hb]).
```

Equivalently,

```text
P(a|H) P(b|Ha) = P(b|H) P(a|Hb).
```

#### Proof

Each product telescopes to the ratio of the common refined cylinder mass to
the initial cylinder mass.  Positivity makes every displayed conditional
well-defined.  No Markov property, time coordinate or action representation
is needed.  ∎

The receipt verifies 1,024 instances: every positive four-atom integer
measure with atom weights in `{1,2,3,4}`, and every choice of the two binary
record values.  The enumeration is a hostile control; the proof is the ratio
identity.

### 3.1 What the theorem does not say

The theorem does not require equal weights for two distinct serial histories
that later push to one quotient atom.  If `q` forgets construction order, then

```text
(q_* mu)(omega_bar)
  = sum_{omega : q(omega)=omega_bar} mu(omega).
```

Nor does the theorem give a conditional kernel on an arbitrary coarse
boundary.  That needs sufficiency.

### Theorem 2 — finite boundary sufficiency

Let `pi:X->B` be a coarse boundary statistic on refined states, and let
`L_x` be the pushed next-record law from refined state `x`.  A kernel
`K(.|b)` satisfying

```text
K(.|pi(x)) = L_x
```

exists exactly when

```text
pi(x)=pi(x')  implies  L_x=L_x'.
```

#### Proof

Necessity follows because both refined states would be assigned the same
kernel row.  For sufficiency, define the row for `b` using any member of its
fibre; fibre constancy makes the definition independent of that choice.  ∎

This is finite lumpability or predictive sufficiency.  It is a condition on
the declared boundary, not a consequence of local update arity.  Paper 27's
separation between bounded local event support and unbounded finite-stop
predictive width remains intact.

## 4. The functional level

### 4.2 Decoherence functional

For class vectors `v_alpha`, define

```text
D(alpha,beta) = <v_alpha,v_beta>.
```

Then for arbitrary coefficients `c_alpha`,

```text
sum_{alpha,beta} c_alpha^* D(alpha,beta) c_beta
  = ||sum_alpha c_alpha v_alpha||^2
  >= 0.
```

Strong positivity is therefore structural.  The D34c fixture has an exact
rank-four `8x8` functional and additive restrictions


functional.

## 7. K-flat is an h-ratio, not a quantum fingerprint

Let a finite acyclic completion tree have positive terminal weights `W(t)`.
For a prefix `x`, define the continuation weight

```text
h(x) = sum_{t extends x} W(t).
```

Then define

```text
K_h(y|x) = h(y)/h(x)
```

for a one-step child `y` of `x`.

### Theorem 4 — positive completion ratio

Every row `K_h(.|x)` normalizes, and the product along a terminal path `t`
telescopes to

```text
W(t)/h(root).
```

Any two paths to the same refined prefix have the same telescoped ratio.

#### Proof

The child continuation sets partition the parent's continuation set, so the
child `h` values sum to `h(x)`.  Multiplying successive ratios cancels every
intermediate `h`.  ∎

D40 checks the theorem for uniform continuation count, nonuniform positive
classical terminal weights and exact Bell/Born terminal weights.  D39's
separate depth-three completion registry retains 21 normalized rows, 78/78
squares and 179 terminal paths.

K-flat's shape is therefore a positive `h`-ratio or Doob completion form.  A
Born/decoherence-functional terminal weight is one possible `h`; a classical
continuation count is another.  The form neither selects `h` nor diagnoses a
quantum origin.
