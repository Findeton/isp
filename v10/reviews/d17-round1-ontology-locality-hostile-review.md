## Executive finding

D17's intended conclusion is correct, but the current executable does not yet
prove the advertised causal-history/record-measure theorem.

The exact receipt holds the scalar D16 action `S=N_0` fixed on two four-element
orders.  It then supplies two different normalized amplitude vectors and two
different orbit-weight conventions.  Unsurprisingly, those choices give
different recorded weights.  This is a valid finite witness that an action
phase alone does not determine separately supplied state/reference data.

The stronger claims fail at four integration points.

1. **Action, state and measure are not separately represented.**  The object
   named `equal_boundary_state` already has the action phases multiplied into
   it.  Orbit weights are calculated later but never enter the amplitude or
   D14 record calculation.  H0's factorization is described in the protocol,
   not executed.
2. **The record is declared, not generated by a local causal interaction.**
   A direct D14 isometry copies the global binary label “chain versus diamond”
   into a protected record and emits a collar.  There is no environment,
   interaction, explicit commit decomposition, or causal-order-local
   opportunity.  The map is a supplied global alternative reader.
3. **The projective towers are not towers of causal orders or extensions.**
   `000` and `101` are hard-coded binary mark strings.  No `CausalOrder`, typed
   collar, truncation of an order, or `Ext(C)` operation appears in them.  The
   prefix test proves projectivity of two finite string tables, not a
   causal-order history measure.
4. **The non-Markov cell carries no local memory.**  The earlier bit remains in
   the tuple key and is read directly when the conditional is formed.  There
   is no hidden boundary carrier, local transport circuit, or memory-deletion
   control.  It is a universe-ledger representation of the finite path, which
   H6 expressly forbids as the implementation claim.

There is also no executed interference/record contrast.  The two order
alternatives are represented as orthogonal system basis vectors before the
seal.  Summing their two scalar components to zero is equivalent to choosing a
particular effect, but that effect is not modeled.  The record copy retains
the already orthogonal system label, and the receipt never evaluates the same
later interference observable before and after record insertion.

The theorem note acknowledges several of these failures and leaves formal D17
incomplete.  That honesty must control the verdict.  The exact packet should
be renamed a **fixed-action boundary/orbit freedom and supplied-record/tower
compatibility witness**, not frozen as complete action-to-measure
nonselection under H0–H7.

## O1 — action, state and orbit measure are conflated

H0 freezes the finite analogue of

```math
A(C)=\Psi_{boundary}(C)\,\mu_{orbit}(C)^{1/2}\,e^{iS(C)}.
```

The executable computes the fixed phases correctly:

```text
chain4   -1
diamond4 +1.
```

It then defines

```python
equal_boundary_state = (ROOT_HALF * phases[0], ROOT_HALF * phases[1])
```

This is not the equal boundary state.  It is already the final phase-weighted
amplitude vector for an implicit unit orbit measure.  The check that its
components sum to zero therefore mixes state preparation and action.

The delta object has the same problem:

```python
delta_boundary_state = (phases[0] * ONE, ZERO).
```

Changing it does show that a separately supplied amplitude envelope can alter
record probabilities while the phase function stays fixed.  But the source
does not execute H0's separation or prove which factor changed.

The orbit conventions are computed later as rational probabilities:

```text
uniform            (1/2,1/2)
normalized 1/Aut   (2/3,1/3).
```

Neither is square-rooted into an amplitude or propagated through the record
seal and tower.  Thus H1/H7 orbit-measure nonselection is illustrative rather
than integrated.

### Required repair

Create explicit immutable fields for `psi`, `mu`, `phase` and `amplitude`.
For each packet check

```text
amplitude[j] = psi[j] * sqrt(mu[j]) * phase[j];
normalization/decoherence derived from amplitude once;
only the intended field differs between countermodels.
```

If exact square roots leave the current number field, choose rational-square
orbit weights or extend the exact arithmetic rather than silently replacing
amplitudes with probabilities.

## O2/O3 — the interference and record experiment is not realized

The code represents the alternatives as two basis states of a two-level
system.  Those basis states are orthogonal before any record exists.  The
statement

```python
equal_boundary_state[0] + equal_boundary_state[1] == ZERO
```

can be read as the amplitude of an unnormalized erasing effect `(1,1)`, but no
effect or recombination morphism appears in the experiment.

The D14 seal performs

```text
|j>_alternative -> |j>_system |j>_record |live>.
```

It retains `|j>_system`, so the branches remain distinguished by both system
and record.  The receipt then checks their record probabilities and mutual
inner product.  It never applies the same erasing effect after the seal and
traces/ignores the record.  Therefore it does not prove that **inserting the
record changes an interference observable**, the explicit H2 countercontrol.

There is also no reason yet to sum the two causal orders coherently.  The
`chain4` and `diamond4` objects have no typed boundaries.  A path integral can
sum distinct fillings only when they share the appropriate external boundary
data and measure sector.

### Required repair

Give both orders identical typed external collars.  Define one boundary
effect/recombiner.  Evaluate:

```text
unrecorded: coherently merge alternatives -> destructive interference;
recorded:   correlate with orthogonal R, apply same system effect, ignore R
            -> incoherent nonzero probability.
```

Born weighting must appear once in both paths.

## O4 — the order record is declared globally

`record_seal()` is a valid D14 isometry.  It gives a persistent record ID,
one owner and a live collar, and the later identity future preserves it.

It does not derive a record from the causal action or an order-local
interaction.  Its input is already the global binary classification

```text
0 = completed chain4;
1 = completed diamond4.
```

The map copies that classification directly.  No local element/collar can
compute it incrementally; no environment is injected; no interaction selects
a pointer basis; and no explicit environment-to-protected-record commit is
separated from the copy.

This is a supplied measurement of the completed history, not an autonomous
causal-order record law.  The theorem note says the commit is supplied, which
is correct.  Receipt labels such as “causal-order record seal” should not imply
that the order action generated it.

For a local claim, construct a causal/matter environment whose boundary state
is transported through extensions, then apply an explicit D14 commit.  If the
global alternative measurement remains the intended witness, call it a
supplied terminal coarse graining.

## O5 — the projective tower is not a causal-order tower

`projective_tower(weight0,weight1)` returns three dictionaries:

```text
depth 1: 0, 1
depth 2: 00, 10
depth 3: 000, 101.
```

The keys are tuples of bits.  They are not `CausalOrder` objects, marked
orders, or extensions of chain4/diamond4.  The prefix operation `child[:-1]`
is not a causal-order truncation map.  No element is born, no order relation is
extended and no boundary/collar ownership is updated.

Consequently the statement “fixed action supports distinct complete recorded
history laws” is too broad.  The fixed action is defined on two size-four
orders, while the tower marks live at three unrelated string depths.  The
source does not evaluate `S` on tower atoms or map the tower's first bit to the
two causal orders through a typed construction.

The valid statement is:

```text
The two supplied record-weight vectors can be extended to two compatible
depth-3 binary mark tables.
```

To pass H5/H7, construct explicit finite spaces `Omega_n` of causal orders or
marked causal histories, define `pi_{n+1,n}` as deletion/restriction with
typed-boundary handling, and push the action/state/measure/record law through
those maps.

## O6 — non-Markovity is read from the ledger, not local memory

The displayed conditional is algebraically correct on the hard-coded table:

```text
P(z=1|y=0,x=1)=1,
P(z=1|y=0,x=0)=0.
```

But `x` is read from the complete tuple key.  No hidden carrier stores X; no
local transition transports it; and the tower construction simply writes
`z=x` by hand.  This is exactly a finite universe ledger representation.

H6 requires one integrated causal-history/record packet whose memory crosses
local boundaries and a deletion control that changes the visible process.
Neither exists.  The theorem note explicitly admits the missing local memory
deletion control, so the protocol grade must remain open.

Reuse the D14/D15 pattern: add a hidden memory carrier, copy X locally,
transport it through a common Y boundary, reveal it into Z, seal all visible
marks and compare with a complete memory-reset channel.  Integrate those marks
with actual causal extensions rather than a separate four-bit toy.

## O7 — orbit weight ontology

Uniform weight on isomorphism classes and normalized inverse-automorphism
weight are both legitimate **supplied conventions**.  Relabeling invariance
does not select either.  D17 states this correctly.

H1 asks for more: labeled and unlabeled sums must agree under one printed
groupoid convention.  The receipt does not enumerate the `4!/|Aut|` labeled
presentations, divide the labeled sum by `4!`, or compare the result with the
`1/|Aut|` unlabeled sum.  It only reads automorphism counts and normalizes two
candidate vectors.

That is sufficient to illustrate orbit-measure freedom, not to close gauge
normalization.  A future repair should execute the labeled/unlabeled equality
and then propagate the selected reference measure into amplitudes and tower
probabilities.

## O8 — projectivity and null domains

The prefix sums for depths one through three are exact, and the inconsistent
table correctly demonstrates that independent level normalization can violate
projectivity.

The receipt does not provide the all-depth induction/extension required by H5.
It also omits zero-probability atoms from its sparse dictionaries.  That is a
valid support representation, but the full atom space and the rule that
conditioning is undefined on null parents must be printed.

The delta tower contains a zero first-level branch; the code wisely does not
divide by it.  The theorem should explicitly state the positive-cylinder
conditioning domain rather than leave it implicit.

## O9/O10 — extensions, joins and clock scope

No `Ext(C)` object appears in the executable.  There are no typed input/output
collars for the causal orders, owner-preserving births, join entitlements or
forbidden-extension test.  Therefore H8 and its unowned-join countercontrol are

A projective whole-history measure can avoid choosing a total update order as
fundamental.  It does not automatically yield a locally computable sampler,
proper time or a law for which extension opportunities exist.  The theorem
does not make that overclaim and should preserve the distinction.
