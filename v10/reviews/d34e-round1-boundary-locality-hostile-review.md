## 2. What B2 and B3 actually establish

The distinction in the pin is physically meaningful.

### B2 is behavioral

B2 is the quotient

```text
(A carrier, multiset/histogram of degrees of A's current neighbors),
```

with optional stopping counters. The full generator partitions exactly into:

- A birth, idle and outgoing rows;
- one silent birth row for each current neighbor;
- one incoming-to-A row for each current neighbor;
- rows that change neither the quotient nor the licensed C output.

Because the last class cannot change any future rate relevant to C in this
frozen law—there is no sealing, component joining or rate dependence on remote
carrier/tip data—the histogram is a genuine strong lumping, not just a
one-step rate fit. The O2 derivative witness correctly shows why the smaller
instantaneous-rate summary B1 does not close recursively.

### B3 is a plausible physical realization, not a histogram stored in A

The B3 data can be read as:

```text
A-owned row and incident port handles
+ for each incident x, an x-owned eligible-degree/birth-count datum
+ typed A--x incidence and a role label, modulo relabeling.
```

That datum is record-local in the chosen D34b ontology. With no joining or
dynamic sealing, an actor's eligible degree changes only when that actor
births; its private birth/adjacency row therefore owns the update. If B births
a child, B's degree changes locally while A's row does not. If B later
interacts into A, the rate `1/(4 degree(B))` is available at B and the A--B
port already supplies the target role. No hidden disconnected history is
needed.

This does **not** mean A alone stores or knows the histogram. It means the
predictive carrier is distributed over the active radius-one star. It also
does not mean the reference Python program uses independent OS actors: the
program remains a central evaluator of a support-local ideal generator.

The physical interpretation is therefore defensible. The two major findings
below concern missing theorem gates between these objects and the final
verdict.

equivariance and construction-order covariance are separate properties. The
scorecard nevertheless emits `L covariance: pass`, and E6 consumes E5 while

their updates commute, that fresh child names extend the gauge consistently,
and that the same physical boundary results at the same fixed-time, A-own-ring

- B3 is explicitly distributed; A alone need not possess the neighbor data.
- Passive incoming receptions are distinguished from A-own rings.
- Exponential memorylessness is confined to the chosen Poisson law; no renewal
  generalization is claimed.
- Fixed radius is explicitly separated from bounded degree, port count and
  integer size.
- No dynamic sealing or component joining is smuggled into the theorem.
- Disconnected components are used only as a product negative control.
- Branch F's every-fixed-radius result remains a candidate-class obstruction,
  not a whole-component minimality theorem.
- Predictive omission performs no physical deletion, so NSE is correctly
  `not applicable` here.
- The reference simulator's result is assigned to the ideal probability law,
  not to deterministic PRF randomness.
- No Lorentz covariance, finite propagation speed, spacetime light cone,
  proper time, v9 posterior sufficiency, intrinsic quantum boundary or

The word “local” is therefore not relativistic in this receipt. It means that
the ideal generator reads an actor's incident star and each event has bounded
