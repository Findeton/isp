## 3. MINOR findings

### m1 — “validated full-history composition” is wider than the implemented validator

The exact set-union theorem is clean on messages produced by
`region_message(state, region)`.  The validator also rejects the six frozen
interface corruptions and the five independent corruptions in the terminal
boundary review.  It does **not**, however, validate a regional message as a
well-formed record DAG.

I constructed three fresh malformed inputs that pass `validate_message`:

1. Both singleton messages for one `A -> B` event were changed consistently so
   that the event names absent predecessor `B#r99`.  The B-owned event does not
   exist.  The B message nevertheless accepts it as opaque, and composing A and
   B continues to retain `B#r99` as opaque even though its encoded owner lies
   inside the union.
2. An A-owned event was made its own predecessor.  Because that predecessor is
   visible, the opaque-reference set is empty and the self-cycle is accepted.
3. After two A events, A's tip was changed from the latest event to the older
   visible event.  Visibility and wire-touch checks pass, so the stale tip is
   accepted.

The independent attack prints:

```text
opaque predecessor owned inside input accepted True
opaque predecessor owned inside union accepted True
self-cycle accepted True
stale visible tip accepted True
```

The reason is precise.  The current validator checks ownership sets, shared
content agreement, port/edge typing, the equality of declared and computed
opaque-reference sets, and whether a tip points to some visible touching
event.  It does not check:

- that an opaque predecessor's encoded owner is outside the region;
- event-DAG acyclicity or predecessor chronology;
- that a tip is maximal on its wire; or
- complete agreement between actor counters and visible local history.

This does **not** refute the composition identity for legitimate projections,
the B4 product theorem or any outcome-table row.  It does refute an expansive
reading of phrases such as “opaque predecessor references are validated” and
“validated typed union” as a complete physical-history integrity check.

**Required repair — choose one and state it explicitly:**

1. **Narrow the claim.**  Say that inputs are assumed to be legal regional
   projections of a D34b state and that the validator checks interface/ownership
   consistency, not intrinsic record-DAG validity, chronology, authenticity or
   seal verification.  Replace “opaque when the referenced event is outside”
   with “opaque when absent from the visible regional event set” unless the
   outside-owner condition is actually checked.
2. **Strengthen the artifact.**  Parse/transport predecessor ownership, require
   an internally owned predecessor to be visible, reject cycles/future
   ordinals, verify wire-tip maximality and cross-check locally owned history
   against counters before allowing composition.  Then add coordinated
   corruptions, not only one-field mismatches.

The first repair is sufficient for Paper 22 because its sufficiency theorem
uses genuine projected messages.
