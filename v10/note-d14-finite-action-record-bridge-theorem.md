## 1. Scope

Let `Sigma` be a finite typed signature.  A type `t` carries a finite
dimensional complex vector space `H_t`.  A generator has a typed source and
target word and a supplied linear map between their tensor carriers.

`FSDiam(Sigma)` is the free strict symmetric monoidal category generated by
that data, with finite acyclic circuit diagrams as morphisms.  Equality is
generated only by the strict symmetric-monoidal relations.  This is a class
of finite typed sealed-diamond circuits, not a category of every physical
spacetime region.

## 2. Evaluation theorem

There is a unique strict symmetric-monoidal functor

```math

```

that maps each type to its carrier, each supplied generator to its supplied
matrix, identities to identity matrices, composition to matrix
multiplication, tensor to Kronecker product and symmetries to permutation
matrices.

**Proof.**  The matrices satisfy units, associativity, interchange, and the
symmetric coherence relations.  The universal property of the free strict
symmetric-monoidal category therefore gives existence and uniqueness.  The
exact receipt independently evaluates nontrivial unit, associativity,
interchange, naturality and involution cells.

For fixed external basis labels, every component of `Z(N)` is the finite
contraction

```math
Z_N(b,a)=sum_{internal labels} product_{v in N} K_v(b_v,a_v).
```

All topological contraction schedules of the same **supplied** diagram agree.  Any two
linear extensions of the finite dependency order are connected by adjacent
swaps of incomparable contractions.  Such swaps exchange either independent
tensor factors or finite sums/products of scalars; interchange and finite
distributivity preserve the result.  The schedule is consequently an
evaluation-schedule gauge.  The causal order of overlapping generators
remains part of the diagram and is not gauged away.  This result does not
generate the diagram, select amplitudes among alternative diagrams, or prove
a local next-extension law.

## 3. Boundary-frame covariance

Under independent unitary frame changes `G_e` on boundaries, a generator
kernel transforms as

```math
K_v -> G_out K_v G_in^dagger.
```

The two factors on every glued internal edge cancel.  Boundary states and
effects transform dually, so closed probabilities are invariant.  More
generally, for `G in SL(2,C)`, a positive state and dual effect transform as

```math
X -> G X G^dagger,
E -> (G^{-1})^dagger E G^{-1},
```

and `Tr(EX)` is invariant.  This is an exact boundary pairing statement.  It
does not derive continuum Lorentz symmetry or a spacetime metric.

## 5. Whole-history law

system class operators `C_alpha`.  Sequential local seal generators
accumulate an orthogonal protected history record `|alpha>`.  The
record-extended branch vector is

```math

```

Then the record-extended decoherence functional is

```math

= <Psi_beta|Psi_alpha>
= delta_{alpha,beta} Tr(C_alpha rho C_alpha^dagger).
```

The bare functional `D_0(alpha,beta)=Tr(C_alpha rho C_beta^dagger)` need not be
diagonal.  The physical orthogonal record carriers produce the displayed
`D_R`.  Thus the recorded partition is exactly decoherent, positive and normalized.
No second stochastic rule is inserted: the diagonal Born weights are the
cylinder probabilities.

```math

= Tr[C_alpha rho C_alpha^dagger sum_z M_z^dagger M_z]

```

cylinder the next-record rule is its disintegration

```math

```

The exact receipt constructs the seals sequentially, checks depths one through
three, and freezes the displayed conditional at exactly `1/2`.  The
completeness identity proves the finite-depth induction.

## 6. Visible non-Markov dynamics

The bridge does not assume visible Markovianity.  A reversible local circuit
can retain the first visible outcome in a hidden carrier, make the current
visible record the same on two branches, and reveal the memory later.  The
receipt obtains exactly

```text
P(z=1 | y=0,x=1)=1,
P(z=1 | y=0,x=0)=0.
```

The enlarged circuit is unitary while this finite visible process depends on
its earlier record.  One integrated local packet has sequential seals,
projective cylinders and the displayed non-Markov conditional.  A CPTP memory
reset removes the dependence and changes the visible law.  This proves finite
compatibility, not that every arbitrary full-history law has bounded local
memory or realizes Barandes dynamics.
