## 4. THE THEOREM — grammar-1 raw flatness is depth-free

**Round-supplied.** The first delivery's residue 1 sketched the locality
half and asked whether it closes. It does not close by itself; the round
closed it, and the completed proof re-sites the finding. Stated for the
d42b3 placement grammar over any finite actor pool.

> **Theorem.** Let `h` be any history of the d42b3 placement grammar over
> any finite actor pool, and let `e_A ≠ e_B` both be admissible at `h`
> with both orders admissible. Then
> `q(e_A|h)·q(e_B|h·e_A) = q(e_B|h)·q(e_A|h·e_B)`, i.e. `A_D ≡ 0`, **at
> every depth**.

**L1 (past-locality). `[THEOREM]`** — `admissible(acts, e)` computes
`pred = event_poset(acts+[e])` and `view = View(acts2, pred, pred[j])`.
Every field the weight reads — `props`, `arbs`, `resolved`,
`superseded`, `live`, `holdings`, `incomparable`, `edges`, `components` —
is a function of the events indexed by `pred[j]` and of `pred` restricted
to that set, which is downward closed. Hence `q(e|h) = Q(e, D(e))` with
`D(e)` the labelled induced sub-poset on `e`'s down-set. *Gated:
T5.L1 — 2,708 keys, 0 clashes.*

**L2 (comparability = register overlap). `[THEOREM]`** — `event_poset`
links `j` to `last[r]` for each `r ∈ regs_of(acts[j])`; appending `e_A`
sets `last[r] = |h|` exactly for `r ∈ regs(e_A)`. Hence
`e_A ∈ pred[e_B] ⟺ regs(e_A) ∩ regs(e_B) ≠ ∅`.

**L3 (disjoint ⇒ commuting). `[THEOREM]` from L1+L2** — if the register
sets are disjoint, `D(e_B)` is the same labelled induced sub-poset in
`h·e_A·e_B` as in `h·e_B`; so `q(e_B|h·e_A) = q(e_B|h)`, and
symmetrically. *Gated: T5.L3 — 40,507 + 1,923 + 630 squares, 0
violations.*

**L4 (an overlapping closed square always contains an idle).
`[PROVED, gated]`** — `regs` of a `p`/`n` event by `a` is `{a}`; `regs`
of an `r` event is `{proposers} ∪ {new value}`, and admissibility forces
the initiator into the proposers. So an overlap between two non-idle
events means they share an actor `a`, and: **(p,p)** — after `a` proposes
on its unique available base that base carries a live proposal of `a`, so
`prop_options_in_view` empties and the second `p` is blocked; **(p,r)** —
`a`'s proposal is in the arbitrated component, so after the `p` the
component's `ckey` no longer matches and after the `r` the base is
superseded, blocked either way; **(r,r)** — the first arb supersedes the
base and resolves the proposals, so the second's `ckey`/component no
longer matches. Hence one member has kind `n`. *Gated: T5.L4 —
23,464 + 516 + 96 squares, 0 without an idle member.*

**L5 (idle inertness). `[THEOREM]`** — `View.props` filters on kind `'p'`
and `View.arbs` on kind `'r'`; a kind-`'n'` act contributes to no field,
so `q(e|h·n_a) = q(e|h)`. *Gated: T5.L5 — 0 violations.*

**L6 (the idle weight is the constant `3/4`). `[PROVED, gated]`** —
`q(n_a|h) = 1 − ¼[has_p] − ¼[has_r]` in `a`'s own view. **L6a:**
`holdings(a) = {V0} ∪ {value created by each arb in the view in which a
is a proposer}`; each such arb supersedes its own base, and `a`'s chain
contains all of `a`'s events, so `a` holds at most one live proposal at a
time and can arbitrate a given base at most once — `a`'s holdings form a
chain all of whose members are superseded except the newest. **L6b:**
therefore exactly one of two states holds, `S0` (no live proposal of `a`:
the unique non-superseded base is free ⇒ `has_p = T, has_r = F`) or `S1`
(a live proposal on that base ⇒ `has_p = F, has_r = T`), and the
transitions `S0 →(a proposes)→ S1 →(any arb resolving a's proposal)→ S0`
preserve the dichotomy. Either way `q(n_a) = 3/4`. *Gated: T5.L6 —
68,750 / 19,767 / 6,868 pairs, spectrum `{3/4}`, `(has_p,has_r)` never
`(T,T)` or `(F,F)`, available bases ∈ `{0,1}`.*

**Proof.** If `regs(e_A) ∩ regs(e_B) = ∅`, apply L3. Otherwise by L4 one
member is `n_a`; by L5 `q(e|h·n_a) = q(e|h)`; by L6
`q(n_a|h) = q(n_a|h·e) = 3/4`. Both products equal `3/4 · q(e|h)`. ∎
