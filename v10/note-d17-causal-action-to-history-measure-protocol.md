# D17 protocol — from causal action to quantum history measure and records

**Status:** frozen before D17 executable outcomes, 2026-07-11.

## 1. Question

D16 proves that poset relabeling and interval dependence do not select action
coefficients.  Even after one action is supplied, its pure phases are not a
normalized history law.  D17 asks:

> Given a fixed finite causal action, what additional data are necessary and
> sufficient to produce a normalized, projective, possibly non-Markov
> whole-history measure with durable D14 records—and are any of those data
> selected by the action itself?

## 2. Frozen packet fields

```text
Omega_n             unlabeled typed causal histories at depth/size n;
mu_orbit             explicit orbit/automorphism reference measure;
Psi_boundary         boundary/initial state or preparation amplitudes;
S(C)                 fixed causal action;
A(C)                 regulated amplitude including measure/state/action;
R                     record/coarse-graining instrument;
D(alpha,beta)         decoherence functional;
pi_{n+1,n}            truncation map between history levels;
P_n                   normalized cylinder probabilities;
Ext(C)                allowed typed extensions/collars;
unit/geometry bridge  influence, dimension, scale and G dictionary.
```

## 3. Gates

### H0 — action/state/measure separation

Write

```math
A(C)=Psi_boundary(C) mu_orbit(C)^{1/2} exp(iS(C)/hbar)
```

or the exact finite analogue.  No factor may be silently absorbed into `S`.

### H1 — gauge/orbit normalization

Labeled and unlabeled sums must agree under one explicit groupoid convention.
Automorphism factors are a supplied measure choice unless a theorem selects
them.

### H2 — interference and records

Unrecorded alternatives sum coherently.  A local D14 environment/commit map
must generate orthogonal record carriers before diagonal probabilities are
claimed.  Inserting the record must change an interference observable.

### H3 — Born once

The decoherence functional is derived from the amplitudes/state once.  No
second click probability is multiplied afterward.

### H4 — normalized finite histories

`D` is Hermitian, positive and normalized on the recorded partition.  Null
cylinders and conditioning domain are explicit.

### H5 — projective extension

For every parent cylinder,

```math
P_n(C)=sum_{C':pi(C')=C}P_{n+1}(C').
```

At least depths 1–3 and an induction/extension argument are required.  A
separate normalization at each `n` does not pass.

### H6 — visible non-Markov law

One integrated causal-history/record packet must give the same current visible
record with different full-past next conditionals.  Hidden/growing boundary
memory must be carried locally rather than read from a universe ledger.

### H7 — action nonselection of state/measure

Hold `S`, `Omega`, types and record instrument fixed.  If two inequivalent
boundary/orbit packets pass H0–H6 but predict different recorded probabilities,
the action-to-measure derivation is nonunique.

### H8 — extension grammar

The action on completed orders does not itself define `Ext(C)`.  Typed collars,
ownership and join entitlements must be explicit; forbidden extensions reject.

### H9 — clock scope

Whole-history/projective consistency may avoid a preferred global update
order.  D17 must distinguish that from a locally computable sequential sampler
or physical proper time.

### H10 — geometry handoff

No V9 holdout opens until the selected measure and record map produce a fixed
influence/dimension/cone/scale prediction with independently fixed nuisance
parameters.

### H11 — hostile closure

Independent quantum-measure mathematics, ontology/locality and clean-room
reviews must attack state/measure freedom, decoherence, projectivity, memory,
record locality and claim scope.

## 4. Countercontrols

```text
two opposite phases cancel when unrecorded;
orthogonal records remove that interference and yield normalized diagonals;
changing the boundary state while holding S fixed changes probabilities;
changing an orbit weight while holding S fixed changes probabilities;
independent per-level normalization fails projectivity;
memory deletion changes the visible process;
an unowned extension/join rejects;
V9 access refuses without H10.
```

```text

  the fixed action uniquely supplies all H0–H11 packet fields and passes an
  untouched prediction;

CAUSAL-ACTION-TO-MEASURE-NONSELECTION
  one fixed action admits inequivalent state/orbit/projective record measures;

CONDITIONAL-CAUSAL-ACTION-RECORD-BRIDGE

```

Even a proved nonselection theorem does not complete the thread objective; it
identifies the next physical datum that independent evidence must select.
