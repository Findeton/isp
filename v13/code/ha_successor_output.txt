  declared link contributes a weight that is a function of ITS OWN interval
  count alone.  At d = 2 that reads, component by component,
     Lambda^11 = f_1(n_e1) + f_3(n_diag),  Lambda^22 = f_2(n_e2) + f_3(n_diag),
