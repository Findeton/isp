## 3. Primitive input and exact row law

The generic estimator receives a serialized finite object

\[
D^{\mathrm{cert}}=
\bigl[
\mathsf{Type},\mathsf{Op},\mathsf{Sel},\mathsf{Comp},
\mathsf{Prep},\mathsf{Ctx},\mathsf{Probe},\mathsf{Read},
\mathsf{RecCand},\mathsf{Gauge}
\bigr].
\]

Every field is operational input. None may contain a hidden factor name,
target region name, coordinate, circuit-wire label, causal arrow, topology,
metric, field propagator, or expected result.

### 3.1 Operation classes

Each operation class contains:

- a presentation handle, ignored by scientific equality;
- exact source and target boundary types;
- an independently supplied exact amplitude representative;
- a complete exact operational signature;
- an independently selectable or composite-only declaration;
- exact gauge data sufficient to decide the declared finite equivalence.

Operational aliases may be quotiented only when signatures, boundary types,
selectability declarations, and every incident composition row are congruent.
Otherwise the input is `ACCESS-UNDERDETERMINED` and cannot earn a positive
rung.

### 3.2 Complete typed rows

For every ordered, type-compatible pair and declared context, the table has
exactly one row

\[
(a,b,\tau,\mathsf{status},c,M).
\]

Here:

- `a`, `b` are operation classes;
- `tau` is the exact composition/boundary context;
- `status` is `IMPLEMENTED`, `UNAVAILABLE`, or `COLLAPSED`;
- `c` is the result class exactly when the status supplies a result;
- `M` is the independently supplied exact composite amplitude law exactly
  when the status supplies a physical law.

Validation reports the following as separate gates:

1. boundary and context typing;
2. status/result/law presence consistency;
3. result-class membership;
4. exact well-formedness of `M`;
5. exact comparison of `M` with the physically composed input laws;
6. declared finite gauge equivalence between `M` and the result-class law;
7. equality of the independently measured operational signatures.

An unavailable row has `c = M = None`. No matrix product or canonical law is
inserted for it. A collapsed row is rejected at the status gate for positive
addressability even if its supplied law is otherwise well typed. This status
rejection is recorded separately from a measured noninjective multiplication
collision among `IMPLEMENTED` rows.

### 3.3 Exact scope

The first theorem is restricted to a finite, single-composition-type,
unital, associative, invertible quotient object on the positive path.
Unavailable and collapsed rows remain valid negative/control inputs. This
finite group-like scope is a provisional access model, not a claim that all
quantum processes are groups.

## 4. Independently operable address factors

Let `Sel` be the quotient classes declared independently selectable. For a
candidate closed subobject `A`, define

\[
\langle A\cap\mathsf{Sel}\rangle_{\mathsf{Comp}}.
\]

`A` is independently generated only when this closure is exactly `A`. The
identity alone does not generate a nontrivial factor. The estimator must read
the selectability field when constructing this closure.

A tuple `(A_1,...,A_k)`, `k >= 2`, is a positive address factorization only
when all of these predicates pass:

1. **independently selectable generation:** every `A_i` is generated by its
   independently selectable classes;
2. **two-order mixed implementation:** every required mixed pair between
   distinct factors is `IMPLEMENTED` in both orders;
3. **exact operational commutation:** both orders have the same quotient
   result and gauge-equivalent independently supplied row laws/signatures;
4. **faithful multiplication:** the map

   \[
   A_1\times\cdots\times A_k\to\mathcal M_D
   \]

   is injective after the explicitly typed central/scalar quotient;
5. **closure:** each factor and every claimed product/restriction closes under
   implemented composition and involution;
6. **typed intersection:** pair intersections contain only the declared
   identity/central scalar object;
7. **represented-algebra product:** the exact represented algebras commute,
   have the typed scalar intersection, and generate the ambient represented
   algebra with the certified product dimension;
8. **restriction stability:** every factor product used as a regional object
   inherits a valid typed composition object, and every claimed restriction
   preserves the preceding predicates at its scope.

These are conditions of operational co-addressability only. They do not mean
spatial separation or no-signalling.
