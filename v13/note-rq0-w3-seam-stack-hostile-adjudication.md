## 4. Adjudicated failures

### 4.1 Incomplete probe and preparation scopes can manufacture a seam

The operator reviewer supplies an exact counterexample. A write/control pair
and eraser satisfy the displayed tests, while a continuation mixes two coarse
sectors for one admitted probe. Selecting only a different, favorably aligned
singleton probe makes that same continuation pass Definition 4.3.

The paper freezes every finite typed subfamily independently of the candidate
$R\subseteq F$, but that temporal independence does not make the subfamily a
complete physical observation context. If all finite subfamilies are
included, fortuitously aligned singleton probes are included too. The same
problem applies to preparations omitted from the packet.

This finding is accepted. The fixed branch-memory control survives because it
uses all four computational preparations and probes. The general object must
instead require a physically complete outcome instrument, a frozen separating
probe context, and an explicit preparation-scope rule before it can be called
a stable W3 seam rather than a packet-relative witness.

This is a no-smuggling failure for the first registered positive rung.

### 4.2 The contextual operational quotient is not the displayed groupoid

scalar contexts. Definition 5.3 nevertheless constructs its objects from raw
matrix seams and its arrows only from passive unitaries. It does not:

- construct nested C*-algebra candidates inside $\overline D$;
- add contextual-equivalence arrows or a second quotient;
- prove that rank, positivity and embedded projector structure descend; or
- identify raw candidates differing only on invisible structure.

The congruence proof also does not explicitly establish compatibility with
linear sums and scalar multiplication despite calling the process language
dagger-linear.

Both reviews' finding is accepted. The quotient's abstract existence does not

### 4.3 Inaccessible-spectator invariance is false as stated

For an ordinary process arrow $a:H_x\to H_y$, the formula

$$
a\longmapsto a\otimes I_K
$$

is typed. For a preparation $\eta:\mathbb C\to H_x$, it produces

$$
\eta\otimes I_K:K\to H_x\otimes K,
$$

not a preparation from $\mathbb C$. Dually, $f\otimes I_K$ is $K$-valued,
not a scalar probe. Proposition 7.6 therefore does not define the claimed
functor on the represented operational theories.

Choosing a spectator state/effect would repair this elementary typing but
would not establish the stated action-groupoid equivalence. Spectator
unitaries that fix the selected state can add ineffective stabilizer isotropy.
Equivalence of groupoids preserves object automorphism groups. Retaining all
stabilizers while deleting this spectator isotropy requires an explicit
rigidification or quotient that the paper does not construct.

This joint finding is accepted as an explicit mandatory-invariance
counterexample. It directly warrants the registered
`RQ0-L0-BLOCKED-AT-SEAM-INVARIANCE` disposition.

### 4.4 Strong equivalence lacks action-equivariance data

Definition 2.4 includes an equivalence of passive presentation groupoids but

The objectwise conjugation theorem is valid. Equivalence of the action
groupoids requires an equivariant functor and coherence data not present in

### 4.5 Complete Karoubi fibers were replaced by invertible cores

The pin requires all admitted Karoubi morphisms. Definition 12.3 retains only
invertible intertwiners. Minimality of an idempotent object does not make every

The paper's own two-dephasing control supplies an omitted map:

$$
e_mhe_n=h.

For distinct nonorthogonal Bloch axes this arrow is noninvertible. It is
admitted by composition and is deleted from the paper's fiber.

The core-groupoid fibration is correct. The preregistered complete
category-valued addressability fibration is not constructed, so the third
rung fails independently as well as cumulatively.
