## §7. THE FIVE MOST VALUABLE TO REPRODUCE FIRST, RANKED

**Ranking criterion, stated so it can be argued with.**  Value =
(how much of the corpus's physics content the reproduction carries into v11)
× (how close the object already is to renewal grain)

impressive; a result already living on a generated carrier scores well even
