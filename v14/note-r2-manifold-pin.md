## 1. What R2 inherits (binding readings)

From the R1 adjudication: **no arena was earned** (φ < 1 is forced by
the basepoint; componentwise overlap completeness ≡ 1).  **The
criterion:** locality exists iff some *component* has a non-complete
overlap graph.  **The recipe (theorem R2-A, to be re-proved in-unit at
this family's actions):** under regular-orbit drawing the overlap
graph is always a union of cliques — locality can only come from
*declared partial orbit overlap*.  **The null control:** the
regular-orbit atlas, guaranteed clique-only.  **The copy-forcing
theorem:** per-block structure carries all content — so R2 works at
the block, not the tower.

## 2. The question (falsifiable, two-sided)

**Does any drawing rule in a declared finite grid of atlas
declarations produce a component with a non-complete overlap graph —
and where locality appears, what do the manifold standards measure?**

Verdicts, both first-class, derived in-gate with flip mutants per
#234/#257 and the new #10 addenda:

- `R2-LOCALITY-AT-<computed rule list>` — naming which declared rules
  yield non-complete components, with the manifold-standard results
  (link profiles, dimension reading) at those rules as computed
  qualifier segments;
- `R2-NO-LOCALITY-IN-THE-DECLARED-GRID` — with the clique theorem's
  in-unit verification carried as the explanation.

## 3. The arenas (data, §15)

- **B** = the single block L₁ (8 labels, TB3's native arena via I6),
  the object the copy-forcing theorem says carries all content.
- **B₂** = L₂ (two blocks + basepoint) as the cross-block control:
  any locality found at B must be re-measured at B₂ to check whether
  it survives (or interacts with) block addition.
- The full-tower members are NOT rebuilt (the forcing theorem makes
  them redundant); this is stated, not silently assumed — one gate
  confirms the per-block reduction on a sampled quantity.

## 4. The declared atlas grid (the object under study; finite,
enumerated, declared here)

Cells are orbit-type sets of the transport action ⟨γ⟩ (and, in the
symmetric variants, ⟨γ, Σ⟩), drawn from exactly this grid:

- **G0 (null):** regular ⟨γ⟩-orbits — the R1 rule; must reproduce
  clique-only components (the in-unit R2-A verification).
- **G1 (subgroup orbits):** for every subgroup H < ⟨γ⟩ in the declared
  subgroup lattice, cells = H-orbits.  Partial overlap becomes
  possible where H-orbits of *different* cells share labels under the
  drawing relation.
- **G2 (coset unions):** cells = unions of a declared number c ≥ 2 of
  H-cosets, for each (H, c) pair in the lattice with c·|H| < the
  block size — the declared mechanism for *partial* orbit overlap.
- **G3 (Σ-mixed):** the G1/G2 constructions under ⟨γ, Σ⟩.
- The grid is enumerated exhaustively in-unit from these declarations;
  its size is printed and gated (cell-completeness over the grid); no
  rule outside the grid is measured; the grid IS arena data — printed,
  matched every coordinate, and carried as a named verdict coordinate
  (the R1 atlas lesson applied at birth).

**Drawing relation per rule:** identical to R1's (drawn iff a unique
transport element carries a → b), so the only variable is the declared
cell structure.  Any rule whose relation refuses (draws nothing) is
recorded REFUSES, not skipped.

## 5. The measurements (registered here)

At every grid rule, at B and (for locality-positive rules) at B₂:

1. **Per-component overlap-graph completeness** — the criterion; the
   locality census over the grid is the unit's core table.
2. **Component spectrum** — component count and sizes (b₀ data).
3. Where a non-complete component exists: **link profiles** at every
   chart of that component and the **dimension reading** (per the I3
   definitions, reimplemented — the raw extensive estimator remains
   excluded); the TOP manifold standards ported as disclosures at this
   scale (one component of one block is far from manifoldhood claims;
   the standards are measured, the verdict does NOT use the word
   manifold).
4. **The two block constants under the new atlases**: N_coh density
   and b₂ density per rule (both denominator conventions) — does any
   locality-bearing rule keep them defined and constant from B to B₂?
   (Connects R1's constants to declared locality; recorded as a
   table, not a verdict clause.)
5. **b₁ per component** at locality-bearing rules (the first chance
   for non-trivial degree-1 topology since I3's trivial-H₁; measured,
   disclosed).

## 6. Controls and falsifiers (minimum set)

- G0 must return clique-only (the theorem check); a mutant corrupting
  the orbit machinery must flip it.
- A hand-declared toy rule with *known* partial overlap (constructed
  in the pin's spirit: two coset-union cells sharing exactly one
  label) must return non-complete — the positive control for the
  criterion's instrument.
- Scramble control on the drawn maps at one locality-bearing rule (or
  at the toy if none): moves the identification-sensitive measures,
  fixes the component census.
- Mutants: grid-enumeration drop (a subgroup or (H,c) pair silently
  missing must die on the grid cell-completeness gate), per-rule
  census corruption, completeness-verdict flip, REFUSES-vs-skip
  conflation, verdict name↔value pairing (the #10 lesson class),
  trajectory/table cell corruption against the render-from-gated-
  object rule, anchor-hash per R0 row used.
- The verdict string: complete-string equality against a
  segment-by-segment rebuild (#10 addendum), every segment flippable.

## 7. Inheritance discipline

I6 (the block, TB3's receipt) and I3 (topology definitions) arrive
hash-verified at run time; the R1 adjudication note is pinned by hash
as the source of the criterion/recipe readings; the copy-forcing

continuum, no claim about manifolds — this unit measures whether
locality can be *declared into existence* and what the standards then
say.  The word "manifold" appears only in the rung's name.
