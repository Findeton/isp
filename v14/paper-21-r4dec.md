## 2. The arena, declared as data (RUNBOOK §15)

### 2.1 The base object and the variable

The base object is d66's `CONFLICT-GRID(g = 3, R = 4)`. Nine actors sit on a
3 × 3 grid, so the actor names parse as a bijection onto Z_3^2 and this unit
assigns no site. Each round spends the committed budget: three conflict groups
of three cells each, partitioning the grid, each running one cycle of the
committed transport grammar — the conflict-supply deliveries from the group's
seed to any member that does not already hold the base, then three proposals,
then one 3-proposer arbitration won by the seed. The variable is the schedule:
which cell-triples arbitrate per round, and which member seeds each group.

A round is a partition of the nine sites into three triples with a seed chosen
in each. The partition count is computed by two routes that share no code —
exhaustive enumeration returns **280**, the closed form 9!/(3!^3 · 3!) returns
**280** — so a round has 280 × **27** = 7560 schedules and the R = 4 family has
**3,266,533,992,960,000**. The grouping quadruples alone number
**6,146,560,000**.

### 2.2 The generalized driver is the committed constructor
