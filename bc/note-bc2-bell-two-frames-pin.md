# BC2 — THE BELL-TWO-FRAMES PROBE: does the conditioning structure
# need a foliation? (PIN)

**Status:** PIN, STRICT, 2026-07-28.  **Program:** BC (bc/LOG.md #1).

## The question

Every realist beable ontology before this one (Bohm, GRW-matter,
Nelson) reproduces relativistic *statistics* while its *ontology*
picks a frame.  Barandes' model of a Bell experiment has definite
configurations at all times, an external time parameter, and division
events located at times.  In frame F1 Alice's measurement precedes
Bob's; in F2 the reverse.  **Are the two frames' indivisible-process
descriptions the SAME ontology under the Lorentz map, or two different
ontologies with the same statistics?**  The pre-registered hypothesis
space includes the interesting positive: because the framework REFUSES
to specify intermediate-time joint distributions (that refusal is
exactly indivisibility, and [B3] calls the realizers "potentially
unknowable"), its specified ontic content may be strictly sparser than
Bohm's — and might be frame-mappable precisely because it says less.
Lean NONE either way.

## The unit

- **The model, exact.**  Singlet state; Alice and Bob projective
  measurements at spacelike separation; at least two setting pairs
  (angles chosen so all probabilities are exact algebraic numbers —
  e.g., 0/45/90 giving entries in Q(√2)); preparation as the initial
  division event.  Build the [B3] composite process in BOTH frame
  orderings: F1 = (prep, A, B), F2 = (prep, B, A).  Every transition
  matrix from the quantum dictionary, exact; the unistochasticity of
  each leg checked with the committed U3 criterion (reused,
  program-independent, anchored).
- **The specified-content inventory.**  For each frame: the division
  event set; the configuration space at each division event; the
  transition matrices between division events; every single-time
  marginal the model defines; every division-event joint it defines.
  Print the inventory COMPLETELY — the comparison must be over what
  the framework actually specifies, no more (no trajectory joints the
  framework refuses) and no less.
- **The comparison.**  Construct the candidate frame map (relabeling
  of division events + configurations under the Lorentz
  correspondence) and test EXACTLY whether it carries F1's specified
  content onto F2's: (i) the outcome statistics (must match — gate,
  this is QM's no-signaling, a control not a finding); (ii) the
  conditional/post-division states and matrices (the ontic content —
  THE test); (iii) the division-event sets themselves.  Census every
  mismatch exactly.
- **The covariance-class verdict.**  Whatever the outcome, state it
  against the weakened-covariance menu of the finite-stochastic
  Lorentz no-go (../v11/note-L1-lorentz-no-go-lemma.md, the committed
  L-1 — its source theorem applies to [B3]'s kinematics directly:
  fixed finite configuration space + stochastic maps; quote it and
  place the finding on its ladder: exact / statistical / projective /
  order-level).
- **The escape-hatch test.**  If mismatches exist, test [B3]'s own
  resources against them: does dropping the intermediate-time
  marginals (keeping only division-event content) restore the
  isomorphism?  Does system-centricity (BC1's subject — cite, do not
  duplicate) change which division events each wing's description
  carries?  Each escape either works (say exactly what it costs) or
  fails (say exactly where).

## Pre-registered outcomes (lean NONE)

- **R-COVARIANT:** the specified content is frame-isomorphic — the
  sparse ontology dodges the foliation problem BECAUSE it specifies
  less than its predecessors; a sharp positive for [B3], stated with
  its exact scope (this model, these settings).
- **R-FOLIATED:** the specified content differs between frames — the
  ontology requires a foliation while the statistics do not; the
  mismatch census is the deliverable, placed on the L-1 ladder.
- **R-CONDITIONAL:** isomorphic only after dropping/adding a stated
  axiom — the price list is the deliverable.
