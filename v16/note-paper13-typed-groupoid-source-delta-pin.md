
where `endpoint_role` distinguishes the source and target occurrences at an

## 5. Configuration action closure

### 5.1 Closed API

The public action derives its target; it does not accept a physical target
chosen by its caller:

```text
act_configuration(source_node, configuration, witness)
    -> ConfigurationTransport
```

This is the exact public signature: three positional parameters, with no
optional target, variadic argument, default, global, mutable closure, cache,
or alternate action/transport entry point capable of accepting a caller
target.  The assertion gate below is the sole target-consuming verifier and
cannot construct or return a transport.  A frozen AST and backward-slice gate
proves that `target_node` is derived only from the exact `source_node` and
`witness`; the configuration supplies state values but cannot select the
target carrier.

`source_node` is an exact `BoundaryNode`, not bare boundary bytes.  The action
derives `target_node` at the same structural address and endpoint role in
`BoundaryNodes(witness.target)`.

The verifier/test surface also has one mandatory assertion gate:

```text
assert_configuration_target(source_node, asserted_target_node, witness)
    -> derived_target_node
```

It independently derives the target node, requires exact node equality, and
refuses before invoking `act_configuration` or constructing any transported
configuration when they differ.  It is not a second physical action and is
never on the successful production call path except as an integrity
assertion.

`ConfigurationTransport` is an immutable exact object containing:

```text
witness identity
complete source-node bytes
complete derived-target-node bytes
source-configuration bytes
transported-configuration bytes
```

It describes one edge only.  It contains no residual involving a witness that
was not passed to this call.

The mandatory assertion gate compares the supplied assertion with the complete
derived target node, including structural address, endpoint role, and
`relabel_boundary(source_node.boundary,witness)`, before any target assignment
or configuration is constructed.  A target mismatch refuses; it never returns
a value plus a false diagnostic.

### 5.2 Preconditions

Before action:

1. the witness is an exact validated `SourceGroupoidWitness`;
2. the exact source node belongs to `BoundaryNodes(witness.source)`;
3. the configuration validates on that node's exact boundary;
4. every configuration matter name belongs to the witness source matter
   carrier;
5. every sector port belongs to the witness source port carrier;
6. every contextual role and type belongs to the witness source role carrier;
7. the target node is derived by the same total completed witness maps at the
   identical structural address and endpoint role;
8. the exact derived node belongs to `BoundaryNodes(witness.target)`.

After action, the result validates on the exact derived target node.  Matter,
sector, context, port mode, and all coefficient-zero catalogue coordinates are
transported, not reconstituted from a weaker assignment-compatible target.
Raw AST addresses remain provenance and are not promoted to physical
ontology; equal semantic nodes produce equal physical configuration action
while retaining distinct, directly checked provenance rows.

### 5.3 Exhaustive laws

Functor laws are separate immutable exact rows with all required data supplied
explicitly:

```text

inverse_action_row(source_node,q,w)
composition_action_row(source_node,q,w,v)
associativity_action_row(source_node,q,w,v,u)
tensor_action_row(tensor_source_node,tensor_q,
                  left_node,left_q,left_w,
                  right_node,right_q,right_w)
```

The tensor row derives the tensor witness and target internally and refuses if
the declared factor nodes/configurations do not reconstruct the complete
tensor source node/configuration exactly.

The identity constructor derives the exact typed `id_X` internally from the
supplied complete `source_presentation`, validates
`source_node in BoundaryNodes(X)`, and stores the full presentation and
identity-witness bytes.  Each constructor validates exact presentation
matching and composability,
calls the closed one-edge action for every constituent edge, threads each
derived target node as the next source node, and stores the complete
constituent `ConfigurationTransport` objects on both paths.  It compares the
final `.transported_configuration` values and exact final target nodes.  A
summary equality without both paths is non-evidence.

For every configuration of every boundary node in every native census row,
derive and serialize the explicitly typed paths:

```text
t_id   = act_configuration(node,q,id_X)

t_w    = act_configuration(node,q,w)
t_back = act_configuration(t_w.target_node,
                           t_w.transported_configuration,w^-1)

t_v    = act_configuration(t_w.target_node,
                           t_w.transported_configuration,v)
t_vw   = act_configuration(node,q,v o w)

t_u    = act_configuration(t_v.target_node,
                           t_v.transported_configuration,u)
t_R    = act_configuration(node,q,u o (v o w))
t_L    = act_configuration(node,q,(u o v) o w)
```

The identity row compares `t_id` with the literal input node/configuration;
the inverse row compares `t_back`; the composition row compares `t_v` with
`t_vw`; and the associativity row compares `t_u`, `t_R`, and `t_L`, including
their final nodes and configurations.  Tensor rows analogously compare the
two factor transports with the complete tensor transport.

Every row retains exact typed node/source/target bytes on both sides.  The
source node and its derived target node are threaded through every composite.
Repeat on tensor factors and on all source and target catalogues used by
operator and Gamma covariance.  Counts alone are not evidence; every
coordinate is emitted and independently recomputed.

### 6.2 CertificateTransportTriple

The exact certificate action has one closed signature:

```text

    -> CertificateActionInput
```

It has no optional literal, registry, cache, global, variadic argument, hash
preimage, or alternate action path.  A frozen AST/backward-slice gate requires
every transported literal to derive only from the completed witness and the
validated complete input.  The full witness is restricted at the recorded
generator AST address; the restricted witness acts on the generator
subpresentation and every certificate field while the full witness carries the
enclosing provenance.

Before action, require `witness.source` to equal the input's complete enclosing
presentation, the generator address to exist there, and the complete input to
revalidate.  Derive the target generator at the same address in
`witness.target`; transport both boundary nodes and both configurations through
the closed configuration action; preserve the exact law coefficients and law
identity; and construct the returned complete input only with the closed
factory on those transported literals.  No caller-selected target presentation,
node, Arrow, configuration, or certificate is accepted.

For each original complete input `b` and witness `w`, emit one immutable
`CertificateTransportTriple` containing complete canonical bytes for:

```text

literal transport          act_certificate(w,b)
independent transformed    rebuild_certificate_input(
                               transformed law/Arrow/transition literals)
```

The literal transport is produced field-by-field by the completed witness.
The independent rebuild starts from the transformed law, Arrow, exact source
configuration, nonzero primitive transition coordinate, and target; it does
not call the transport function and does not reuse transported fields.

The literal and rebuilt complete inputs, including their embedded inherited
