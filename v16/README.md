# ISP v16 — joint relational-history dynamics

v16 is the investigation era for the proposed **joint relational-history
law**: relational facts, effective geometry, process content, and durable
records belong to one history rather than to separately coupled machines.

The era begins with paper 01, `JRH` (joint relational history).  It asks two
separate questions:

1. Can that architecture be made mathematically coherent without treating a
   fixed spacetime, nonlinear mixture evolution, or a privileged global
   Hamiltonian as fundamental?
2. If it can, do the stated principles select a law, particle content, affine
   term, gravitational constants, or observable deviations from QFT/GR?

The second question is deliberately harder.  A consistent toy model is not a
theory-selection result.
