## 2. Frozen object 1 — process-complex space and its σ-algebra

$\mathsf{Cpx}$ is the set of isomorphism classes $[\chi]$ of unmarked
process complexes: complete typed execution diagrams with boundary
sorts, generators, and physical carrier, marks forgotten, exactly as
typed in the Paper 17 joint-law note §2. The σ-algebra $\Sigma_\chi$ is
the **presentation-invariant** one: generated by the cylinder events
"$[\chi]$ restricts to a fixed finite diagram fragment up to groupoid
transport." No refinement by presentation coordinates, serialization
order, or labels beyond groupoid classes is admissible. Finitary
approximation: $\Sigma_\chi$ = colimit of its finite-subcomplex
restrictions (projective family in §4).

## 3. Frozen object 2 — allowed root/boundary variables

A root variable is any function $\rho:\mathsf{Cpx}\to\mathbb R_{\ge0}$
built from the finite invariants of §2's fragments: occurrence count,
component count, generator-vertex multiset by type, bond counts,
carrier size, fusion-vertex count $v(\chi)$ (Paper 23a Def), frontier
supports. **Not allowed** as root inputs: anything involving an order
or rank on carriers, X/Y port orientations beyond groupoid classes,
private seeds, or any object carrying an orientation that Γ_D itself
does not carry. This is the anti-smuggling wall at the input side.

## 4. Frozen object 3 — the admissible projective family of $\Pi_{\rm phys}$

$\mathcal P$ is the set of all probability measures on
$(\mathsf{Cpx},\Sigma_\chi)$ such that:

1. each finite restriction (fixed carrier-size budget $N$) has a
   finitely supported marginal;
2. the family $\{\Pi_N\}_{N}$ is projectively consistent under the
   deletion maps (13D §14: deleting an occurrence descends the complex);
3. covariance: $\Pi_N(g[\chi])=\Pi_N([\chi])$ for every presentation
   morphism $g$;
4. scheduler independence: for complexes differing only by
   staged-vs-simulated scheduling of the same generators (distinct
   traces per 13D §10.2), no member of $\mathcal P$ may assign mass by
   a schedule-dependent rule — weights are functions of $[\chi]$ as a
   point of $\mathsf{Cpx}$, full stop.

Every statement below quantifies over **all of $\mathcal P$**
(universal) or over **named pre-registered subfamilies**
(existential); the named subfamilies are: $\mathcal P_{\rm unif}$
(uniform on each finite restriction when normalizable),
$\mathcal P_{\rm v}$ (weights depending only on fusion-vertex count),
$\mathcal P_{\rm size}$ (weights depending only on carrier size).
No other subfamily may be introduced after seeing results.

## 5. Frozen object 4 — the candidate orientation extractor

The extractor $\mathcal E$ is any admissible observable (P23c Def 2.2)
valued in exchangeable realizer-pair classes (the #330 target type:
ordered pairs of total orders modulo simultaneous transport and rank
swap). The gate question: does there exist $\Pi\in\mathcal P$ and an
admissible $\mathcal E$ defined on the joint-law fibers such that
$\mathcal E$ applied under $\Gamma_{\rm struct}(\cdot,\cdot)$ yields a
well-defined, nonconstant orientation assignment realizing the
intersection condition? "Nonconstant" means: distinguishes the two
#330 witness classes $[(L,\mathrm{rev}\circ L)]$ vs $[(L,L)]$ on some
positive-mass fiber.

## 6. The four-way classification to be decided

For each clause, state universal ($\forall\Pi\in\mathcal P$),
existential ($\exists\Pi$ in a named subfamily), or not-selected,
with proof:

- **(Q1)** Orientation is *already* a measurable covariant function of
  physical $[\chi]$ alone (then $\Pi$ is irrelevant to it);
- **(Q2)** Some declared $\Pi$ makes a previously ambiguous extractor
  unique almost surely **by support restriction alone** (zero-mass on
  all fibers but one realization type);
- **(Q3)** Distinct orientations remain within one $[\chi]$-fiber
  (same complex, different history-class realizations): then **scalar
  reweighting cannot distinguish them**, since $\Pi$ is constant on
  fibers — this would be the deep negative form;
- **(Q4)** Smuggling audit: was any orientation input through ranks,
  labels, root fields outside §3, support choice, or a refined
  σ-algebra?
