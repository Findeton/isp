## 2. Shared ontology doctrine

The user instruction is binding for all seats.

- A lattice, graph vertex, causal-set element, triangulation cell, basis row,
  circuit layer, update counter, or tick may be used as a regulator or receipt
  only. It may not silently become the ontology.
- The candidate ontology is one actual compatible web of durable relational
  facts. Regions are bounded parts of that web, not sets of underlying points.
- There is no asserted maximally detailed actual microtrajectory between
  records and no assertion that every alternative filling is an actual world.
- The candidate law is unsliced and regional. A Hilbert space, decoherence
  functional, path integral, graph, stochastic kernel, or Hamiltonian is a
  representation at its stated grain unless separately earned as ontology.
- Representational refinement changes a description; ontic extension adds a
  durable fact. Any argument that conflates them is a major failure.
- Actualization is a postulate. Geometry is unentered unless one relational
  structure supplies calibrated causal, interval, volume, and loop response,
  is changed by physical content, and changes later physical behavior.
