# ISP v16 frontier dependency census

Date: 2026-08-21

Status: **NONBINDING RESEARCH-GOVERNANCE REGISTER**

This register separates scientific derivation from declared input at the live
frontier. It does not adjudicate an unreviewed candidate, alter a terminal
result, or authorize implementation. Its purpose is to make hypothesis
accretion visible before a downstream promotion is attempted.

## 1. Status vocabulary

- **terminal**: independently adjudicated and closed at the printed scope;
- **ledger theorem**: an exact theorem recorded in the committed programme,
  but not a terminal acceptance of every claim in the surrounding draft;
- **internal**: frozen and internally audited, without a blind terminal panel;
- **candidate**: a mathematical construction awaiting semantic review;
- **twice-adjudicated unaccepted**: independently reviewed at least twice and
  not accepted; surviving coordinates carry only their adjudicated local
  scope (Paper 22 line);
- **failed coordinate**: expressly rejected by a terminal counterexample;
- **unconstructed**: no law or object has been supplied.

Dependency kinds are:

- **D** — derived from the bound law;
- **N** — new nomological postulate;
- **C** — independent calibration or apparatus input;
- **S** — contingent state or boundary input;
- **T** — declared target-family hypothesis;
- **G** — presentation/gauge choice with proved prediction invariance;
- **U** — required but unconstructed.

Raw counts of assumptions are not a scientific score. A single new
nomological law is more consequential than several gauge conventions. The
kind and downstream role of each dependency are therefore retained.

## 5. Accretion controls for every successor

Every promotion-bearing successor must publish a row for each new object:

| field | required meaning |
|---|---|
| object | exact physical/mathematical object introduced |
| dependency kind | D/N/C/S/T/G/U |
| frozen before output? | yes/no and bound hash |
| independent motivation | why it is not chosen to obtain a desired result |
| free residue | all parameters, phases, roots, boundary states, and measures left free |
| hostile removal | what theorem fails if the object is removed |
| downstream consumer | which later coordinate uses it |
| promotion ceiling | what it still cannot establish |

The register must reject these substitutions:

- an apparatus setting called a law constant;
- an active mark called an autonomously occurring opportunity;
- conditional channel odds called an activity rate;
- a supplied initial source called a root law;
- a finite truncation called ontological discreteness;
- an oriented decoder called an emergent orientation;
- a declared target geometry called a selected metric;
- a Hilbert/Stinespring representation called physical selection; and
- a result-neutral census called empirical contact.

## 6. Review tier

- **Tier 1 — foundational promotion:** new law, selector, opportunity law,
  chronology, dimension, or metric. Freeze first; independent hostile panel;
  adjudicate before implementation or downstream use.
- **Tier 2 — conditional theorem:** exact theorem inside a declared target
  family. Independent mathematical check and explicit dependency row; no
  full implementation ceremony unless it becomes load bearing.
- **Tier 3 — census/control/no-go preparation:** one internal audit with exact
  counterexamples and immutable inputs. No multi-seat ceremony unless the
  result later supports a promotion.

Paper 23 is Tier 1 because a successful autonomous opportunity law would open
the global Paper 17 ensemble gate.
