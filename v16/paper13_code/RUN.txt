PAPER 13 EXACT REGENERATION

Requirements
------------

- Python 3.11 or later.
- Python standard library only.
- Run from the repository root for the first three commands.
- No network access and no package installation are required.

Fast bundle and paper checks
----------------------------

python3 v16/paper13_code/run_all.py --selftest
python3 v16/paper13_code/run_all.py --verify-only

The first command authenticates every byte-bound file, checks every paper
claim/number block, and proves that an in-memory anchor corruption exits only
through the failure path.  The second performs the same checks without the
deliberate failure probe.  Neither command runs the scientific evaluator or
writes a publication artifact.

Full exact replay
-----------------

python3 v16/paper13_code/run_all.py

The master runner authenticates the manifest, evaluator, paper, fresh case,
official output, official receipt, and verification note.  It creates absent
destinations in a temporary directory, regenerates the fresh case from the
recorded nonce and source hash, runs the byte-frozen evaluator once, and
requires byte-for-byte equality with all three frozen Stage-B artifacts.  The
temporary directory is removed automatically.  A mismatch exits 1 and emits
no replacement artifact.
