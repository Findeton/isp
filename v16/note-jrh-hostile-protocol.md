## Common independence contract

The three reviewers start from the frozen pin, paper, transcript, receipt, and
the relevant parent sources.  Each reviewer:

- writes only its assigned single report file;
- makes no git mutation and no edit to any candidate or prior-era file;
- does not read either other review file, even if it appears while work is in
  progress;
- may use a private temporary directory for scratch calculations;
- must not import, execute, copy functions from, or mechanically translate
  `v16/code/jrh_exact.py` when rebuilding a decisive claim;
- may run the candidate only for black-box CLI/integrity checks after the
  independent rebuild is complete and identified as such;
- uses exact arithmetic for decisive finite claims;
- cites primary literature for external claims and separates literature facts
  from the reviewer's inference;
- reports every alleged error with the exact object, consequence, severity, and
  minimal repair or kill; and
- ends with one grade: `ACCEPT`, `ACCEPT-WITH-FIXES`, or `REJECT`, plus the
  highest licensed primary and secondary verdicts.

A reviewer may confirm the framework while rejecting its physical
interpretation, or reject an implementation claim while preserving an analytic
one.  Corrections run in every direction; agreement with the paper is not a
success criterion.
